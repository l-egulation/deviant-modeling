# DEVIANT 중간발표

DEVIANT의 기획 단계 발표 자료입니다. 발표 시간은 약 13분이며, 교육생과 컨설턴트 대상 발표를 위해 제작했습니다.

## 파일

- [발표 장표](DEVIANT-middle-presentation.html): 이미지·폰트를 포함한 단일 HTML 파일. 다운로드한 뒤 브라우저에서 열면 됩니다.
- [발표 대본](presentation-script.md): 장표별 발화 내용과 발표 전 확인 사항.

## 조작

- `→`, `↓`, `Space`, `Enter`: 다음 장면 또는 다음 장표
- `←`, `↑`, `Backspace`: 이전 장면 또는 이전 장표
- `1`–`9`: 1–9페이지, `q w e r t y u i`: 10–17페이지 바로 이동

장표 내부 애니메이션은 발표자가 다음 키를 누를 때 진행됩니다. HTML은 외부 이미지나 폰트 파일 없이 열 수 있습니다. GitHub의 코드 보기 화면에서는 HTML이 슬라이드로 재생되지 않으므로 파일을 내려받아 브라우저에서 열어 주세요.

이 폴더는 발표 전용 브랜치에만 있습니다. 3D 모델링·Kimodo 모션 연구 파일은 이 발표 작업에서 수정하지 않았습니다.
