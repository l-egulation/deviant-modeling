# DEVIANT 중간발표

DEVIANT의 기획 단계 발표 자료입니다. 발표 시간은 약 13분이며, 교육생과 컨설턴트 대상 발표를 위해 제작했습니다.

프로젝트 2주차 기준으로 무기 변환·강화와 다양한 전투 스타일 경험을 설명합니다. 총 19장이며 대본 목표는 12분 5초이며 나머지는 전환·시안 감상 시간입니다. 장표는 그림과 짧은 핵심어 중심입니다. 12·13장은 새로 생성한 전투 개념 이미지이며 실제 게임 화면이 아닙니다. 원본 PNG와 최종 생성 프롬프트는 [이미지 제작 기록](assets/GENERATION.md)에 있습니다.

인쇄 스타일은 단계별 요소가 모두 보이도록 구성했습니다. PDF 배포 전에는 3장의 세 장면과 8장의 변환 전후 요약을 확인하세요. 이번 수정의 실제 브라우저 렌더링·인쇄 결과는 로컬 파일 접근 제한으로 미검증입니다.

## 파일

- [발표 장표](DEVIANT-middle-presentation.html): 이미지·폰트를 포함한 단일 HTML 파일. 다운로드한 뒤 브라우저에서 열면 됩니다.
- [발표 대본](presentation-script.md): 장표별 발화 내용과 발표 전 확인 사항.

## 조작

- `→`, `↓`, `Space`, `Enter`: 다음 장면 또는 다음 장표
- `←`, `↑`, `Backspace`: 이전 장면 또는 이전 장표
- `1`–`9`: 1–9페이지, `q w e r t y u i o p`: 10–19페이지 바로 이동

장표 내부 애니메이션은 발표자가 다음 키를 누를 때 진행됩니다. HTML은 외부 이미지나 폰트 파일 없이 열 수 있습니다. GitHub의 코드 보기 화면에서는 HTML이 슬라이드로 재생되지 않으므로 파일을 내려받아 브라우저에서 열어 주세요.

3페이지 세계관은 두 번 더 넘기면 장면이 순서대로 나타납니다. PDF의 초반 사건과 맵 설계 요약을 참고하되, 발표에는 핵심 장면과 게임 구조만 담았습니다.

이 폴더는 발표 전용 브랜치에만 있습니다. 3D 모델링·Kimodo 모션 연구 파일은 이 발표 작업에서 수정하지 않았습니다.

## AI 제작 과정 확장

15장은 에테르 AI의 시트와 네 무기 공격 GIF, 16장은 Tripo 기반 외형과 Kimodo 생성 골격, 17장은 Mixamo 적용·비교 실험입니다. 기존 제작 계획은 18장으로 이동했습니다. 두 MP4는 해당 장에서만 음소거 반복 재생하며, 자동 재생이 제한되면 영상의 재생 버튼을 사용합니다. PDF에서는 정지 미리보기가 표시됩니다. 자료 출처와 구분은 [AI 자료 기록](assets/ai-process/README.md)을 참고하세요.
