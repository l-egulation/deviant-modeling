# 특수공격 발표용 연출 시안

- sword-special.svg: 사용자 제공 기본검 공격 시트의 기존 자세를 재배열하고 준비·타격·회복 타이밍과 검격 효과, 적 반응을 추가했다.
- whip-special.svg: 사용자 제공 채찍 GIF 첫 프레임을 그대로 디코딩해 사용하고, 채찍이 뻗고 적을 감싸는 벡터 효과를 추가했다.
- 각각 3.6초 반복 SVG 애니메이션이다. 신규 AI 생성 프레임이나 게임 엔진용 완성 모션이 아니다. 피해량·속박 시간·실제 판정은 표현하지 않는다.
- HTML 8장에 내장했다. 기본검에서 채찍으로 바뀔 때 특수공격 시안도 바뀐다. 기존 원본 GIF와 15장 제작 결과는 유지했다.
- SVG XML·내장 이미지 디코딩을 확인했다. 브라우저 렌더·인쇄는 기존 로컬 접근 제한으로 확인하지 못했다.
