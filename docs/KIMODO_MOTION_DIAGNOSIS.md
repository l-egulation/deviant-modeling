# Kimodo 원본과 적용 과정 진단

2026-10-15, 사용자 요청으로 생성 원본의 단독 재생과 전달 과정의 수치를 확인했습니다. 모션 수정이나 새 생성은 하지 않았습니다.

outputs/kimodo-run-source-preview.mp4 / .gif는 선택한 생성 원본 tripo-run-source.npz의 관절을 측면·정면·사선에서 표시합니다. 수평 진행만 카메라에서 제거했고 수직 이동·관절 위치·재생 속도는 바꾸지 않았습니다. 머리의 원 표시는 관절 위치 표시이며 시선 방향 표시가 아닙니다.

## 확인한 문제

- 원본 머리의 정면 축이 평균 약 24.79도 아래로 기울어 있습니다. steady head looking forward 요청이 충분히 반영되지 않았습니다. 캐릭터 머리 축도 약 24.79도로 동일해, 이 숙임을 전부 리타기팅 오류로 설명할 수 없습니다. 큰 후드가 이를 더 두드러지게 합니다.
- 골반→목 방향 전경은 원본 약 15.67도, 캐릭터 골반→머리 시작점은 약 14.17도로 비슷합니다. 비교 기준점이 완전히 같지는 않으나 과도한 몸통 전경을 추가한 근거는 없습니다.
- 원본 팔꿈치 내부 각도 평균은 약 115.22도이며 150도보다 펴진 프레임은 없습니다. 따라서 팔이 완전히 펴진 모션이라고 단정하면 안 됩니다. 다만 90도 안팎의 간결한 게임 달리기와 달리 낮은 손·열린 팔꿈치의 동작이 생성됐고, 큰 장갑이 달린 짧은 팔에서 인상이 달라집니다.
- 원본 다리 두 뼈 길이 약 0.855m, 캐릭터 약 0.268m로 약 31.4%입니다. 몸 전체를 같은 비율로 줄인 모델이 아니므로 같은 관절 회전이 같은 시각적 보폭을 뜻하지 않습니다.
- 원본 NPZ→표준 T포즈 BVH→Kimodo 왕복 관절 오차 최대 약 0.061mm. 파일 변환이 크게 깨진 증거는 없습니다.
- 기존 발 접촉 보정 전후 상체 회전 차이 0 검사는 접지 함수가 상체를 바꾸지 않았다는 뜻일 뿐, 원본 동작이 자연스럽거나 리타기팅이 미적으로 옳다는 증명이 아닙니다. 국소 옷 늘어짐·두꺼운 의상의 겹침도 남습니다.

## 판단

생성 원본의 시선과 팔 자세 선택 문제, 캐릭터의 다른 신체 비율, 남은 의상 스키닝 문제가 함께 있습니다. 손이 가슴보다 낮은 수치와 구조 검사만으로 원본을 채택한 것이 충분하지 않았습니다. 원본 골격을 먼저 사용자와 확인하고 나서 적용해야 합니다. 지금 단계에서 캐릭터 키프레임을 다시 직접 만들지 않습니다.
