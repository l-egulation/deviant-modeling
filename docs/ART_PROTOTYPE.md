# 2026-10-22 재질·카메라 시험

실제 Tripo A 모델을 포함한 `hero-mixamo-run.blend`의 보정된 Mixamo 달리기 6번 프레임을 사용했다. 메시 정점, 리그, 모션은 수정하지 않았다. `outputs/art-style-prototype/comparison.png`는 왼쪽부터 팀원 정지 참고, 기존 재질 30도, 고정색 측면/30도/45도이다. 참고와 시험본은 자세가 다르므로 비율의 정량 비교 자료로 사용하지 않는다.

원본 UV 텍스처를 면별로 샘플링하여 아이보리/검정/청록/금색 영역을 잠정 분류했다. 질감 대신 고정 방향 법선 기준 2단계 emission 재질을 적용했다. 384px 렌더를 96px 최근접 샘플링 후 지정 팔레트로 양자화하고 알파를 이진화했다. 단순히 기존 조명 렌더의 색 수만 줄인 방식과 구분한다. 면 분류 경계와 명암 방향은 최종 수작업 재질 영역 지정 전 시험 설정이다.

## 검증
- 세 native PNG 모두 지정 팔레트의 6개 불투명 색, 알파 0/255 확인.
- 동일 직교 배율 1.5m/96px, 하향 5도, 발 기준 (48,80), 프레임별 자동 크롭 없음.
- 현재 달리기 자세의 높이는 62px. 중립 자세 64px 규격의 확정 검증은 아직 하지 않았다.
- 실제 출력 및 수치는 validation.json, render-settings.json 참조.
- 기존 파일을 보존하고 별도 prototype.blend로 저장했다.

## 시각 검토
색상과 픽셀 경계는 가까워졌지만 미술 일치 기준 미통과. 측면에서는 얼굴이 거의 보이지 않는다. 45도가 30도보다 얼굴을 읽기 쉽지만 좁은 후드 입구와 숙인 자세 때문에 두 눈의 독립된 세로 형태가 충분히 보이지 않는다. 카메라만으로 해결되지 않는다.

후드는 참고의 뒤로 빠지는 끝 대신 둥근 덩어리이며, 아이보리 그림자 면이 과하다. 스카프는 가는 목 둘레뿐이다. 몸통/바지의 기존 입체 굴곡과 팔 겹침이 큰 로브 면을 끊는다. 금색 영역 자동 분류도 최종 부위 마스크로 정리해야 한다.

다음: 후드/얼굴 입구 부분 수정, 넓은 긴 스카프 구성, 허벅지 위 앞트임 로브 정리. 그 후 같은 색/카메라로 다시 검사한다. 천 물리, 전체 애니메이션 미술 검증은 아직 구현하지 않았다.

재실행: WSL Blender로 scripts/render-art-prototype.py 실행 후 Python(Pillow/numpy)으로 scripts/pack-art-prototype.py 실행. 캐릭터 높이와 정지 참고 자세의 차이를 고려해 최종 카메라는 형태 수정 후 결정한다.
