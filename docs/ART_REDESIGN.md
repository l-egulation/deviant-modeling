# 2026-10-22 3D 미술 재디자인 초안

실제 Tripo A 모델 기반의 부분 수정. outputs/hero-art-redesign/hero.blend가 편집 원본이며 hero.glb는 교환용 리그/메시이다. Blender의 법선 기반 2단계 셰이더는 GLB에서 동일하게 재현되지 않을 수 있으므로 도트 렌더 기준은 blend이다. 원본 hero-proportion-model.glb와 기존 달리기 파일은 변경하지 않았다.

## 수행
- 원본 9,697정점 중 후드 영역 1,356정점 수정. 앞쪽 폭과 뒤쪽 끝 형태 조정. z<=0.64인 팔다리/몸통 정점은 변경하지 않음을 검사했다.
- 기존 텍스처의 금색 눈 분류를 검정으로 정리하고 실제 얼굴 표면 위치에 두 개의 금색 3D 눈 판을 배치했다.
- ArtRobe: 허벅지 위 밑단, 앞트임 있는 독립 옷 메시. 골반/상체 부착 가중치. 기존 몸통 전체를 절차적 캐릭터로 교체하지 않았다.
- ArtScarfTail: 넓고 끝이 갈라진 단일 천 메시와 목 부착 영역. 현재 모양은 정적 설계 자세이며 펄럭이는 물리 결과가 아니다.
- 원본 리그의 팔을 내려 중립 검토 자세로 렌더. 새 달리기 키프레임은 작성하지 않았다.
- 30/45/60/90/180도 렌더. 비교판은 팀원 참고와 30/45/60도. 60도는 두 눈 가림을 확인하기 위한 추가 진단 각도이며 확정 카메라가 아니다.
- 96px 투명 출력, 지정 6색만 사용, 알파 0/255 확인. 출력 캐릭터 높이 63px, 잘림 없음. 중립 기준64px과 1px 차이는 최종 카메라 보정 대상으로 남긴다.

## 미통과/다음
아직 외형 최종 승인 기준 미통과. 후드 입구가 팀원 그림보다 좁고 사선에서 먼 눈이 가려진다. 후드의 끝 방향/길이와 스카프 실루엣도 참고와 다르다. 로브는 현재 너무 평평하며 참고의 명확한 그림자 면과 여밈이 부족하다. 기존 재킷 아래에 추가한 로브이므로 움직임 전 겹친 내부 면을 정리해야 한다. 원본 가중치를 유지한 소매의 어깨 변형도 추가 확인 필요.

Kimodo 새 생성/이식, 스카프·로브 물리/충돌, 정지·달리기·급정지·회전 시험은 아직 수행하지 않았다. 외형을 먼저 통과시키는 단계이므로 결과를 모션 완성본으로 취급하지 않는다. 다음 순서는 얼굴 입구와 후드/로브 형태를 더 맞춘 후 실제 Kimodo 원본 골격 검토, 비율 매핑, 옷 물리 베이크이다.

재현: WSL Blender로 scripts/build-art-redesign.py, Pillow/numpy Python으로 scripts/pack-art-redesign.py. 수치 결과 build.json/validation.json. 렌더 로그 docs/logs/art-redesign.log.
