# 부위별 픽셀 출력 시험 — 2026-10-27

목표는 전체 재모델링 전에 눈·소매·로브·장갑·신발·발목 장식의 구분을 별도로 제어하는 것이다. 이번 비교는 이전 readable-style의 모델, 자세, 물리, 카메라를 모두 유지한다. 원본3D를 바꾸지 않는 대신 눈 등 일부 내부 픽셀의 디자인을 의도적으로 정리한다.

## 결과

`outputs/pixel-part-style/idle-comparison.gif`, `run-comparison.gif`: 이전 출력 / 부위 지도 / 부위별 보정 출력. 각 클립 폴더에 128px 투명 프레임, preview.gif, sheet.png. 색색의 지도는 진단용이며 게임용 색상이 아니다.

기존의 Region 정점 그룹과 원본 텍스처 색을 조합해18개 부위 ID를 면에 부여하고384px로 렌더링한다. ID는 뼈·옷 변형을 따라간다. 신발/다리는 기본 자세 높이로 나눈 근사 분류이므로 제작자가 직접 분리한 정밀 메시 태그와는 다르다.

- 눈/장식: 최종 한 픽셀에 대응하는3×3표본 중3개 이상을 차지하면 작은 장식색을 우선한다. 직전에도 보였다면2표본까지 유지하며, 해당 부위의 얼굴/다리/목 영역 안으로 제한한다.
- 눈: 최초 단순 좌우 좌표 분류는 눈 영역을 잘못 나눠 한쪽이 줄어드는 문제가 있었다. 출력 단계에서 보이는 금색 눈 영역의 연결 성분 두 개를 찾아, 얼굴 내부의2×3~4px 세로 블록으로 정리한다. 완전히 가려진 눈은 생성하지 않으며 가장자리에서는 잘릴 수 있다. 출력 eye.L/R 수치는 화면 순서이지 해부학적 좌우가 아니다.
- 소매/몸통, 소매/장갑, 후드/얼굴: 접하는 위치의 밝은 아이보리 픽셀에1px 그림자색을 넣는다. 일괄 검은 외곽선은 추가하지 않는다.
- 원본 알파는 그대로 유지한다. 눈 보정은 내부 색칠 변경이며 원래 눈 모양을 픽셀 단위로 보존하는 작업은 아니다.

## 검증과 판단

대기90프레임, 달리기22프레임에서 원본 알파 동일과6색 팔레트 검사를 통과했다. 부위 지도 렌더 전후 모든 shape-key 좌표 해시가 동일하다. 기존 골격/옷 계산을 바꾸지 않았으므로 이번에 물리 재검증을 수행한 것은 아니다.

눈과 접합 경계를 별도로 제어할 수 있는 단계에 도달했지만, 전체 화풍이 팀원과 같아졌다고 판단하지 않는다. 특히 소매와 로브의 넓은 겹침은 실제 형태와 투영에 의해 생겨 내부 경계만으로 해결되지 않는다. 발목 장식의 픽셀 우선순위도 원본에 가려져 없는 영역을 복구하지 않는다. 향후 필요한 모델 수정은 전체 재제작보다 소매 폭/몸통 간격, 발목 장식 두께와 같은 부분 수정으로 좁혀볼 수 있다.

시간 안정화는 화면좌표의 가시성 제한 이력만 사용한다. 움직임을 추적하는 보정은 아니며, 빠른 동작에서 단발성 변화가 남을 수 있다. 눈의 연결성분 크기 선택 역시 극단적 가림에서 교체될 수 있다. 루프 연결과 모든 동작의 미술 품질은 미검증이다.

## 재현

Blender4.5.13LTS에서 `scripts/render-part-map.py` 실행 후 Pillow/numpy Python으로 `scripts/pack-part-style.py` 실행. 로그 `docs/logs/pixel-part-map.log`, 분류표와 원본 해시 `outputs/pixel-part-style/part-map.json`, 픽셀 규칙/프레임별 눈·장식 면적 `validation.json`. 입력은 pixel-readable-idle-cloth.blend와 pixel-run-cloth.blend 및 기존 readable-style PNG다.
