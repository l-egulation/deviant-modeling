# 128px 달리기 스프라이트 시험 — 2026-10-23

입력은 목둘레 접합을 수정한 e8b3934의 `outputs/pixel-run-cloth.blend`이다. 실제 Mixamo 달리기와 베이크한 의상을 30fps로 캡처했다. 새 AI 이미지 생성이나 프레임별 화풍 재생성은 사용하지 않는다.

## 출력

`outputs/pixel-run-sprites/`:

- `original/000.png`~`021.png`: 투명 384×384 원본 캡처.
- `128px/000.png`~`021.png`: 128×128, 고정 6색, 이진 투명도.
- `coarse/000.png`~`021.png`: 64×64 논리 격자를 최근접 2배 확대한 128×128 비교안.
- `spritesheet-128px.png`, `spritesheet-coarse.png`: 768×512, 6열×4행, 셀128×128. 행 우선 22장, 마지막2칸 빈칸.
- `spritesheet-original.png`: 2304×1536 원본 시트.
- `run-128px.gif`, `run-coarse.gif`: 투명 재생 시험.
- `comparison.gif`/`.png`: 왼쪽 원본, 가운데128px, 오른쪽굵은격자. `contact-sheet.png`: 번호 포함 검토용.
- `capture.json`: 원본 프레임·시트 배열·팔레트·시점·주기. `validation.json`: 크기·잘림·색·알파 검사.

`outputs/pixel-run-sprites.zip`은 로컬 전달용 묶음. 원본 캡처와 개별 도트 프레임·시트·메타데이터 포함. 중간 render 폴더는 제외.

## 미술 처리

팀원 기준 6색(FDEEDA, D2B396, 1B1616, 025673, 02648C, EBA516)을 사용한다. 원본 UV 색으로 재질 영역을 고정 분류한 뒤 텍스처를 버리고, 아이보리와 청록은 법선 기준 2단계 명암, 검정·금색은 단색으로 렌더한다. 최종 팔레트 투영으로 가장자리 중간색을 없애고 알파는0/255로 제한한다. 분류는 자동이므로 수작업 의미 영역 검토는 남아 있다.

한 장 전체를128px로 줄인 스프라이트 시트가 아니라, **각 프레임이128×128**이다. 고정 직교 카메라는 측면에서 정면 쪽30도, 높이·배율 고정, 루트 수평 이동만 추적한다. 발 기준점(64,112), 프레임별 자동 크롭 없음. 원본 형상·스켈레톤·모션·물리 설정은 변경하지 않았다.

## 검증 및 한계

- 원본45~66프레임,22장,30fps,733.333ms. GIF는10ms 단위 제약으로 총730ms; 게임에서는30fps 사용.
- 두 도트안 모두22장,128×128,지정 팔레트만 사용,알파0/255,모든 프레임 캐릭터 잘림 없음.
- 몸의 주기는22프레임이나 천은 독립 시뮬레이션이다. 같은 위상45/67프레임 비교에서 루트 이동 제거 후 표면 차이 최대0.05750m/p95 0.03134m. **완전한 무봉제 루프가 아니다.** 최종 반복용은 천 주기 보정 후 재캡처해야 한다.
- 색면과 픽셀 밀도는 접근했지만, 팀원 그림과 후드·얼굴 노출·팔다리 겹침의 실루엣 차이가 있다. 최종 화풍 일치나 게임용 완성을 선언하지 않는다.
