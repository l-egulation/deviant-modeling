# 부위별 고정 명암 시험 — 2026-10-26

산나비/데드셀 조사 후 첫 구현이다. 원본 모델·모션·천 베이크는 보존하고 명암 면만 바꿨다. 사용자 최종 승인을 받은 화풍은 아니다.

## 방식

- 이전: 기본 자세의 표면 방향을 평활화해 고정한 그림자.
- 이번: 기본 자세 좌표와 의미별 정점 그룹으로 후드 옆면, 소매 아래, 로브 옆판, 스카프의 색 영역을 직접 지정. 정점 속성이 골격과 천 변형을 따라간다. UV에 손으로 그린 텍스처나 AI 프레임 재생성이 아니다.
- 후드의 첫 뒤쪽 그림자는 카메라에 가려져 너무 평평하게 보여 옆면으로 변경했다. 머리 꼭대기는 기본색을 유지한다.
- 6색 팔레트, 128×128 캔버스, 중립 캐릭터 높이64px. 최종 확대는 최근접. 프레임별 재중심·크기 조절·윤곽 수정 없음.
- 대기는 기존 호흡 동작 1~90, 달리기는 기존 Mixamo 적용본 45~66. 둘 다30fps 표본. GIF는10ms 단위로 시간을 반올림하므로 대기3초, 달리기0.73초다.
- 카메라와 배율은 비교 양쪽에 동일. 이번에 포즈·타이밍·물리를 수정하지 않았다.

## 결과와 검증

`outputs/pixel-painted-style/comparison.gif`: 왼쪽 이전 표면고정 명암, 오른쪽 새 부위별 명암. `run-comparison.gif`는 같은 비교의 달리기다. 각 클립/방식 폴더에128px 투명PNG, `preview.gif`, `sheet.png`가 있다.

`render-validation.json`은 수정 전후 모든 shape-key 좌표 해시 동일, 대기/달리기 동일한 명암 속성을 확인한다. `pixel-validation.json`은112개 자세 각각의 두 방식 알파 동일, 화면 잘림 없음, 재생시간 검사를 기록한다. 화면좌표 색상 변화 지표는 실제 움직임·가림도 포함하므로 깜빡임 개선율로 해석하지 않는다.

후드와 로브의 명암 영역을 더 큰 덩어리로 조절할 수 있게 됐다. 다만 카메라 각도에 따라 그림자 면의 보이는 넓이가 달라지며, 기하 윤곽의 픽셀 경계 이동은 남는다. 높은 후드·좁은 얼굴 입구·겹쳐 보이는 부츠·뒤로 가려지는 스카프는 원본 형상/시점의 특성이므로 이 작업으로 해결되지 않는다. 천의 루프 연결, 전체 몸 충돌, 최종 화풍 일치도는 미검증이다.

다음은 이 색칠 규칙을 유지한 상태에서 대기 주요 자세와 유지 시간을 별도로 비교하는 단계다. 모션 변경 시 천을 다시 계산해야 한다. 원본 형상을 바꾸는 조정과 명암 조정을 혼합하지 않는다.

## 재현

WSL Ubuntu-22.04, Blender4.5.13LTS:

```sh
DESIGNED_SHADOWS=1 /opt/deviant-blender/blender-4.5.13-linux-x64/blender -b --python-exit-code 1 -t 8 --python scripts/render-surface-style.py
python scripts/pack-painted-style.py
```

포장에는 Pillow/numpy가 필요하다. 규칙은 `scripts/pixel_shadow_design.py`, 실행 기록은 `docs/logs/pixel-painted-style.log`. 원본 blend는 덮어쓰지 않는다.
