# 단순 색면과 얼굴 노출 시험

2026-10-23. 사용자와 합의한 대표 한 프레임 우선 검토. 최신 의상 베이크49프레임을 사용하고 기존 전체 애니메이션/시트를 덮어쓰지 않았다.

`outputs/pixel-flat-study/comparison.png`: 팀원 정지 참고 / 기존 동일 달리기 자세 / 새60도·고정 그림자안. 팀원 참고의 본래 높이는64논리px이며 현재 달리기와 자세·화면 높이가 달라 비율 측정 자료는 아니다.

`options.png`: 위는 완전 단색, 아래는 큰 고정 그림자 영역. 왼쪽부터 측면 기준30/45/60도(60도는 정면에서30도)다. 각 `*-128.png`가128×128 투명 원본이다.

변경: 기존 움직이는 표면 법선 기반 명암을 제거하고 고정 emission 색으로 교체. 후드 뒤쪽/로브 한쪽에만 기본 자세 좌표로 지정한 큰 그림자 영역을 부여했다. 청록 목둘레는 강조색으로 구분했다. 원본 UV는 재질 영역 분류에만 사용하고 천 질감은 사용하지 않았다. 모든 결과를 팀원6색 팔레트에 제한하고 알파0/255로 검사했다. 검증 상세 validation.json.

시각 결과: 잘게 나뉜 로브 명암이 줄었고60도 시점에서 얼굴과두눈이 더 노출된다. 그러나 위로 솟은 후드·좁은 얼굴 입구·둥근 소매 단면·겹친 발·짧게 보이는 스카프 실루엣은 남는다. 이는 재질이 아닌 현재 형상/포즈/시점의 문제다. 일부 작은 윤곽 돌기/빈틈도 단색 렌더만으로 사라지지 않는다. 팀원 화풍 일치로 판정하지 않았다.

이번에는 원본 형상, 골격, 모션, 물리를 수정하지 않았다. 전체 프레임의 그림자 안정성과 루프는 미검증. 한 장 방향 확인 후 후드/소매 등 형상 조정 범위를 결정하고 전체 적용해야 한다.
