## 시각 평가

손이 가슴을 가리지 않는 효과는 보입니다. 밀어내는 자세에서 앞뒤 다리 차이가 가장 잘 읽힙니다. 그러나 접지와 받침 자세의 차이가 약하고 낮게 웅크린 인상이 남아 있습니다. 접지 발의 순서·뒤쪽 부츠의 여유·골반이 지지 발 위를 지나가는 경로를 추가로 잡아야 합니다. 네 자세를 최종 승인 포즈나 완성된 달리기라고 취급하지 않습니다.

국소 옷 늘어짐과 접힘은 남아 있습니다. 정점 위치 원본과 리그 크기는 유지했지만 임의 포즈의 의상 품질 검증을 통과한 것은 아닙니다. 세부 수치는 docs/logs/tripo-run-keyposes.json.

재현: Blender 4.5.13에서 scripts/study-run-keyposes.py 실행, Pillow/NumPy 환경에서 scripts/compose-run-keyposes.py 실행. 카메라는 측면 고정, 기존 자세의 전진 이동은 제거했습니다. 원본 데드셀 영상은 저장소에 포함하지 않았습니다.
