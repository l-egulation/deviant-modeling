# 기존 캡처 기반 큰 픽셀 단순화

2026-10-23. 사용자가 screen-study의 눌린 후드 형상을 거절하고 이전 캡처의 디자인을 유지하도록 요청했다. 이전 형상 보정안은 채택하지 않는다.

입력 `outputs/pixel-run-sprites/coarse/000.png`~`021.png`는 형상 변경 전 원본 달리기의 큰 픽셀 캡처다. 새 결과는 `outputs/pixel-simple-run/`에 저장했다. 새3D모델/리깅/모션/카메라 보정이나 AI재생성은 없다.

- 프레임당128×128,64×64 논리격자를 최근접2배 확대: 픽셀 한 칸2×2.
- 사용자 후속 요청으로 아이보리 그림자를 복원. 팀원 팔레트의 FDEEDA/D2B396/1B1616/025673/EBA516 다섯 색 사용. 청록 강조색은 기본색에 통합.
- 그림자는 기존 캡처에서 가져온다.64격자에서4방향 연결영역5픽셀 이상인 덩어리만 남기고, 앞뒤 프레임의1픽셀 이내 영역에도 있는 그림자를 유지한다. 현재 프레임에 없는 그림자를 새로 덧칠하지 않는다. 프레임당 기존61~96픽셀에서38~88픽셀의 그림자가 남았다.
- 22프레임 모두 입력 coarse의 알파와 경계상자가 완전히 동일. 윤곽/머리·몸 비율/프레임 정렬 유지. 모든 색은 지정5색, 투명도0/255.
- `spritesheet.png`: 6열×4행,768×512,22장과빈칸2개.
- `run.gif`:128px투명재생. `preview.gif`:최근접3배확대384px회색배경. `comparison.gif`/`.png`:음영없는 이전안과 큰 그림자 복원안의동일프레임 비교.
- `frames/`:개별PNG. `capture.json`:입력/시트정보/검증. `outputs/pixel-simple-run.zip`:로컬전달용묶음.

30fps원본22프레임(733.333ms),GIF는730ms. 원래 독립 천의 루프 불연속 가능성은 그대로다. 인접 프레임 필터는 작은 그림자의 갑작스러운 출현을 억제하지만 완전한 깜빡임 제거를 보장하지 않으며 루프 양끝을 연결하지 않았다. 팀원과의 실루엣·자세 차이는 남고, 화풍 최종 일치로 단정하지 않는다.

재현: Pillow/numpy가 있는Python으로 `scripts/pack-simple-run.py`. 실행시22장/색/알파/경계/2배격자/GIF프레임 검증을 수행한다.
