# 원본 형상을 보존한 표면 명암 비교

2026-10-26. 사용자 승인: AI가 모델을 재해석한 시안 대신 실제 3D 형태와 움직임을 보존하고 색칠 규칙을 통일한다.

## 결과와 해석

`outputs/pixel-surface-style/comparison.gif`는 동일 대기 모션3초,10fps/30샘플의 세 방식 비교다. 왼쪽 A는 움직이는 실제 법선 기반2단계 명암, 가운데 B는 표면에 고정한 명암, 오른쪽 C는 고정85%+실제 법선15% 혼합이다. `comparison.png`는 첫 자세, `run-poses.png`는 달리기45/49/55프레임에서 같은 규칙의 적용을 비교한다.

이번에는 AI 재생성, 후드/몸 변형, 골격 수정, 포즈 변경을 하지 않았다. 원본3D 파일에도 저장하지 않았다. 색칠 효과를 비교하는 **시험 결과**이며 팀원 화풍 완성본으로 승인한 것이 아니다.

눈으로 볼 때 세 방식의 차이는 크지 않다. B는 그림자 위치가 표면을 따라가므로 작은 명암 변화는 감소했지만 높은 후드·겹쳐 보이는 부츠·몸 뒤로 가려진 스카프는 그대로다. 작은 그림자 조각도 일부 남는다. 형상 보존을 지키면서 명암 안정화를 시험한 결과이지 실루엣 문제를 해결한 결과는 아니다.

## 실제 구현

- 원본: `outputs/pixel-idle-cloth.blend`, `outputs/pixel-run-cloth.blend`. 기존 의상 베이크 그대로.
- 텍스처는 기존과 같은 부위 기본색 분류에만 사용. 아이보리/검정/청록/금색에6색 팔레트 적용.
- 기준 형태(Basis)의 표면 법선을 인접 정점으로30회 평균하여 작은 표면 굴곡 영향을 줄임. 기준 방향(.35,-.55,.76)과의 내적을 `StyleRestLight` 정점 속성으로 저장한다. 정점ID를 따라가기 때문에 애니메이션마다 다시 칠해지지 않는다.
- A: 실제 움직이는 법선의 내적. B: 저장한 속성. C: B×.85+A×.15. 셋 모두 임계값.18의 동일2단계 색면.
- 이것은 **UV에 손으로 그린 명암 텍스처가 아니라 정점 속성에 저장한 절차적 명암 시제품**이다. 실제로 넓고 의도적인 그림자를 디자인하려면 이 고정 마스크를 부위별로 편집하는 단계가 남는다.
- 카메라: 직교, 측면에서60도, 배율1.96, 고정높이.128캔버스에서 중립 캐릭터 높이64px, 발기준y104. 달리기의 굽힌 자세는62px가 되며 프레임별로 다시 확대하지 않는다.
- 모든 비교는384렌더→128최근접·6색양자화·이진알파·공통 좌우반전. 이전 프레임별 작은 그림자 제거 필터는 사용하지 않는다. 부드러운 블러나 잔상 합성도 없다.

## 검증

`render-validation.json`, `pixel-validation.json` 기록:

- 두 입력 각각 모든 shape key 좌표의 SHA256이 작업 전후 동일.
- 대기와 달리기에 생성한 고정 명암 속성의 SHA256도 동일. 모션마다 다른 그림자를 새로 디자인하지 않았음.
- 33개 표본 자세 전부 A/B/C 알파 마스크 완전 동일. 같은 자세의 윤곽을 바꾸지 않음.
- 허용6색, 알파0/255, 프레임 잘림 없음. 대기 GIF3초.
- 대기에서 연속 표본의 공통 불투명 영역 색상 변경 수 평균: A13.62 / B11.69 / C12.00픽셀.
- 한 표본만 바뀌었다 돌아온 색상 픽셀 평균: A1.96 / B0.86 / C1.18.

위 두 수치는 **화면 좌표 기준**이라 실제 움직임·가림도 포함한다. 모션 보정된 깜빡임 측정값이나 지각 품질 점수가 아니다.10fps표본으로30fps잔떨림이나 루프 연결을 보장하지 않는다. 달리기3자세는 시간 안정성 검증이 아닌 적용 가능성 확인용이다.

## 다음 적용 기준

기본 후보는 B. 그림자가 적게 바뀐다는 장점은 있으나 고정 그림자는 방향이 크게 바뀌면 부자연스러울 수 있다. C는 제한된 변화가 필요할 때 비교할 후보이며 현재 시험에서 B보다 안정적이지는 않았다.

원본 형상은 유지한다. 다음은 후드 뒤/아래·소매 안쪽·로브 측면의 고정 마스크를 직접 넓은 면으로 정리하고, 동일 마스크로 대기와 달리기 전체를 검증하는 단계다. 화면에서 작은 그림자를 매 프레임 삭제하는 방식으로 되돌리지 않는다. AI 기준 그림은 색면 배치 참고에만 사용하며 새로운 실루엣 정답으로 삼지 않는다.

## 재현

Blender4.5.13에서 `scripts/render-surface-style.py`를 `--python-exit-code 1`로 실행 후 Python/Pillow에서 `scripts/pack-surface-style.py` 실행. `docs/logs/pixel-surface-style.log`에 렌더 기록. 고해상도중간raw폴더는 제외, 최종PNG/GIF/시트와 검증JSON을 보관한다. 기존 모델과 달리기/대기 결과는 덮어쓰지 않는다.
