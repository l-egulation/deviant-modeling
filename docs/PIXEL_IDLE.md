# 동일 화풍의 제자리 대기 비교

2026-10-26. 사용자가 팀원의 단검 대기 GIF와 비교할 수 있도록 현재 모델/도트 처리로 대기 모션을 요청했다.

입력은 목둘레를 보정한 `outputs/tripo-pixel-rig.blend`. 거절된 후드 눌림/카메라 전용 형상 보정은 사용하지 않는다. 원본 메시 위치·UV·골격 길이는 유지하고 팔을 내린 자세에서 척추/가슴/목/팔에 작은 주기적 회전을 넣었다. **직접 작성한 비교용 호흡 동작이며 Kimodo 생성 또는 Mixamo 대기 모션이 아니다.** 무기는 추가하지 않았다.

발/하체와 루트 위치는 고정.90프레임30fps3초,발 위치 오차0m,골격 길이 오차8.794e-8m. 기존 달리기 베이크를 복사하지 않고 대기 동작에서 로브/스카프/후드 물리를 새로 계산했다. 조용히 선 상태라 목도리는 달리기 때보다 아래로 내려온다.

## 출력

- `outputs/pixel-idle/comparison.gif`: 왼쪽 팀원 단검 대기, 오른쪽 현재 모델 대기. 팀원 원본4프레임의 시간 유지. 한 번 정한 크롭/정수 확대율로 표시 높이를 비슷하게 맞췄으며 두 캐릭터의 논리 픽셀 밀도/무기/자세는 같지 않다. `comparison-side.gif`는 기존 측면기준30도 비교도 보존한다.
- `preview.gif`: 현재 모델384px확대. `idle.gif`:128×128투명.
- `frames/`:90장, `spritesheet.png`:10열×9행,1280×1152,셀128×128.
- `capture.json`:카메라/팔레트/주기/프레임경계/검증.
- `outputs/pixel-idle.zip`:로컬전달용PNG/GIF묶음.
- `outputs/pixel-idle.blend`, `pixel-idle-cloth.blend`:골격동작과 새 의상 베이크.

처음에는 이전 달리기와 같은 측면기준30도로 캡처했으나 대기에서 얼굴이 많이 가려졌다. 최종 비교는 카메라만 측면기준60도(정면에서30도)로 바꿔 얼굴 노출을 확보했다.64논리격자→2배128캔버스,5색과 넓은 아이보리 그림자,그림자 연결영역5픽셀 이상·인접 프레임 지원 필터는 유지한다. 비교 편의를 위해 최종PNG/GIF만 오른쪽을 향하도록 좌우 반전했다. 원본3D형태를 변경하지 않았다.

## 검증/한계

목둘레208쌍은90프레임 모두 간격0. 실제 로브 외면/스카프 꼬리 교차0건,국소 최대 모서리 늘어짐2.191배. 전신/자기/연속 충돌 및 반복 경계의 무봉제 연결을 보장하지 않는다. GIF는 동일한 연속 프레임을 합칠 수 있으나총3초를 유지한다. 약한 호흡은 큰픽셀에서 일부 변화가 생략될 수 있다.

화풍은 비교용이며 최종 일치 승인이 아니다. 팀원은 넓은 얼굴/뒤로 처진 후드/펼쳐진 스카프가 잘 읽히고 현재 모델은 좁게 보이는 얼굴·높은 후드와 입체 소매 형상이 남는다. 이번 작업에서는 이 형태들을 수정하지 않는다.

재현: `build-pixel-idle.py` → `MOTION_TAG=pixel-idle simulate-pixel-run-cloth.py` → `MOTION_TAG=pixel-idle capture-pixel-run.py` → `pack-pixel-idle.py`. Blender는 `--python-exit-code 1` 사용. 의상 검사에는 VERIFY_INPUT/VERIFY_OUTPUT, 목둘레 검사에는 COLLAR_INPUT=outputs/pixel-idle-cloth.blend/COLLAR_TAG=idle 사용. 로그 docs/logs/pixel-idle-*.
