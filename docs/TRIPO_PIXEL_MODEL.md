# 2026-10-22 Tripo 다각도 미술 모델

사용자가 팀원 화풍의 T포즈 입력이 유효하면 55크레딧 생성을 허용하고, 후드 끝/로브 밑단 보존과 다각도 입력을 요청했다.

- 입력: assets/hero-pixel-tripo-input.png. 팀원 원본을 참고하여 built-in image_gen으로 준비한 단일 정면 T포즈 그림. 3D 결과 자체는 아니다.
- 입력 지시: 큰 아이보리 후드/넓은 검정 얼굴/금색 세로 눈, 짧은 앞트임 로브, 긴 넓은 청록 스카프, 팔 수평/다리 약20도 분리, 잔질감·지퍼·잔주름 없이 큰 색 면. 실제 준비 그림에는 약한 그라디언트와 팔/스카프 겹침이 있어 정확한 6색/완전 분리 기준 통과로 취급하지 않는다.
- Tripo Generate Multi-Views로 Front/Left/Right/Back 네 입력 생성. 화면 잔액 변화 없음(2995 유지). 다각도는 AI 추정이며 실제 모델을 회전 촬영한 이미지가 아니다.
- HD Model / H3.1 / Geometry & Texture, 8K 및 Generate in Parts 해제 상태로 1회 실행.
- 55크레딧 사용: 2995 → 2940. 추가 결제 및 구독 없음. Free Retry 사용하지 않음.
- 생성 완료 에셋: e17c5a9c-2576-4917-8f27-10712925121c
- URL: https://studio.tripo3d.ai/workspace/generate/e17c5a9c-2576-4917-8f27-10712925121c
- UI 메시에 1,930,974 삼각형, 1,000,280 정점 표시. 리그/모션 생성 안 함.

## 검토
Tripo 웹 뷰어에서 정면/측면/후면 회전 확인. 후드 돌출 끝과 로브 앞트임/밑단이 실제 입체 실루엣으로 보인다. 뒤쪽 얼굴 중복 없음. 색과 큰 면이 기존 A 모델보다 입력 그림에 가깝다. 후드 끝은 뒤쪽보다 옆으로 뻗고, 스카프와 어깨/팔이 가깝다. 정확한 연결/관통 검사는 로컬 메시 다운로드 후 필요. 로브 길이도 최종 픽셀 출력에서 재검토해야 한다.

웹 모델 생성 완료와 리깅용 구조 통과는 별개. 매우 고밀도이므로 형태 보존 감량/의상 분리 및 관절 시험이 다음 단계다. Kimodo 적용과 천 물리는 미완료.

## 파일 상태
GLB/4k 내보내기를 실행했으나 로컬 파일 저장 완료를 확인하지 못했다. Chrome 다운로드 관리 페이지는 브라우저 보안 정책상 차단되어 우회하지 않았다. 모델은 위 Tripo 에셋 페이지에 저장됨. 로컬 GLB가 있다고 주장하지 않는다. scripts/review-tripo-model.py에는 출처명을 환경변수로 기록할 수 있게 추가했으나 이번 모델에 아직 실행하지 않았다.
