# Tripo 새 모델 천 관성 시험

2026-10-23. 사용자가 물리/관성 시험 또는 필요한 선행 단계를 요청했다.

## 시험 범위

`outputs/tripo-pixel-shaped.blend`의 후드/스카프 수정 모델을 사용한다. Kimodo 달리기 적용본이 아니라 **T자 자세 이동 장치**로 출발, 정속 이동, 급정지, 반대 방향 이동을 시험한다. 카메라는 몸을 따라가므로 화면에서는 몸이 고정되어 보인다. 실제 시뮬레이션의 몸은 월드 Y축으로 이동한다.

- Blender 4.5.13 Cloth, 30fps, 150프레임 중 처음30프레임 안정화. 이후120프레임/4초를 영상에 포함.
- 스카프171정점, 로브333정점의 별도 저밀도 계산 표면. 스카프 뿌리와 로브 상부 고정. 실제 Tripo 렌더 메시를 완전히 잘라 분리한 것이 아니라, 독립 계산 표면의 변위를 원본에 전달하는 시험 구조다.
- 중력, 관성, 공기 저항, 몸 충돌과 자기 충돌 사용. 움직임을 사인파로 직접 만든 것이 아니다. 움직이는 것은 시험용 몸의 위치이며 천은 물리 계산 결과다.
- 머리/몸통/골반/두 다리/두 팔을 단순 타원체 충돌체로 근사. 정확한 원본 표면 충돌이나 관절이 굽혀지는 달리기 충돌은 검증하지 않았다.
- Cloth quality12, collision quality6, 자기 충돌 거리0.003m, 몸 충돌 거리0.004m. 로브 윗부분3줄 고정, 굽힘 강성12. 스카프 뿌리2줄 고정, 굽힘 강성0.8.
- 계산 표면의 가까운4정점 변위를 가중 평균해 원본에 전달. 위치가 겹치는 UV 정점의 변위는 일치시켜 균열을 방지한다. 이 방식이 최종 의상 리깅을 대체하지는 않는다.

## 확인된 문제와 조정

첫 시험에서 스카프가 중력에 내려앉고 급정지 후 지연 반응을 보였지만, 로브 앞트임 주변이 거칠게 접혔다. 밑단 부근의 변형 가중치가 다시0으로 줄어드는 경계를 제거하고 상부 고정 범위를 확대했으며 굽힘 강성과 자기 충돌을 추가해 재시험했다.

물리 반응의 발생과 게임용 외형 품질을 구분한다. 정지 시 스카프가 아래로 처져 폭이 줄어드는 현상은 중력 반응이지만, 팀원 그림의 긴 스카프 실루엣과는 별도 미술 조정이 필요하다. 앞트임 주변의 변형은 재생 영상에서 판단하며, 이번 시험만으로 의상 품질 통과나 관통0건을 주장하지 않는다.

## 결과/재현

- `scripts/test-pixel-cloth.py`: 실제 물리 계산, 프레임 렌더, 계산 표면 좌표 캐시, Blender 재생용 Shape Key 베이크.
- `scripts/encode-pixel-cloth.py`: 120프레임 30fps MP4/GIF, 네 시점이 아닌 네 시간대의 접촉시트. MP4 디코딩 프레임 수 검사.
- `outputs/tripo-pixel-cloth-test.blend`: 원본 외형과 물리 베이크를 포함한 별도 시험 파일. 계산용 Cloth는 베이크 후 비활성화해 저장된 재생 결과를 유지한다.
- `outputs/tripo-pixel-cloth-cache.npz`: 두 계산 표면의150프레임 좌표.
- `docs/logs/tripo-pixel-cloth.json`: 설정 및 매 프레임 끝단 위치/최대 변위.

후드/스카프 정적 수정본은 그대로 보존한다. 다음 단계는 옷자락의 변형 전달과 실루엣 품질 정리 후 실제 골격 모션에서 팔/다리 충돌 시험이다. 반복 루프, 최종6색 도트, 실시간 게임엔진 천은 아직 미검증이다.

## 첫 시험 판정 (아래 후속 수정 전)

- MP4 120프레임/30fps/4초 디코딩 검사 통과.
- 저장한 Blender를 다시 열어31/75/76/90/120/150프레임을 확인. 베이크 좌표와 재생 좌표의 최대 오차 약1.49e-8m로 재생 재현 통과.
- 몸이 정지한76~105프레임 사이 스카프 끝 평균점 누적 이동거리 약0.236m, 로브 밑단 평균점 약0.020m. 정지 후에도 천이 움직이는 반응을 수치로 확인. 누적 이동거리이며 한쪽으로 늘어난 길이가 아니다.
- **게임용 외형 품질은 미통과.** 스카프 처짐/몸 뒤 가림과 로브 앞트임의 거친 변형이 남는다. 몸 충돌체가 근사이며 두 천 사이 상호 충돌은 검증하지 않았다. 자기 충돌을 켰다는 사실만으로 관통이 없다고 보장하지 않는다.
- 다음 우선순위: 실제 옷자락에 맞는 열린 단일 천 표면 및 정확한 변형 전달 → 스카프가 처져도 읽히는 실루엣/부착각 검토 → 골격 적용 후 달리기 충돌. 물리 수치만 반복 조정해 완료로 처리하지 않는다.

## 후속: 로브 겉감/안감 연결 및 스카프 부착 정리

사용자가 정리를 승인하여 같은 모델과 이동 조건에서 수정했다.

원인: 이전 로브 변형 가중치는 텍스처 밝기에 의존했다. 밝은 겉감은 움직이지만 어두운 안쪽 면은 고정에 가까워 연결 삼각형이 과도하게 늘어났다. 단순히 물리 강성이 낮은 문제가 아니었다. 이전 베이크의 같은6프레임에서 로브 가장자리 최대 길이 비율은 약151.5배였고,75프레임에서2배를 넘은 모서리는218개였다. 이는 짧은 초기 모서리 기준의 국소 비율이며 옷 전체 길이가151배라는 뜻이 아니다.

- 로브 위치/반지름 영역을 기준으로 안감과 겉감을 함께 움직이도록 변경. 최상부 고정 전이는 유지한다.
- 가까운4정점 평균을 의상의 높이·둘레 좌표에 따른 격자 보간으로 교체. 앞트임 양쪽은 각자의 끝 열에 연결돼 반대편과 섞이지 않는다.
- 스카프도 길이/폭 좌표에 따라 연결. 부착부를 뒤로0.03m 이동하고 뿌리 고정을2줄→4줄로 확대, 뿌리 곡면의 깊이를 넓혔다. 굽힘 강성0.8→3. 원본 후드와 몸 전체를 재제작하지 않았다.
- 실제 렌더 메시 전체를 새로 리토폴로지한 것은 아니다. 이번 구조 정리는 독립 천 계산 표면과 원본 겉감/안감 사이의 연결을 고친 작업이다.
- 추가 좌표 검사에서 x=0의 앞트임을 가로지르는 연결 면을 확인했다. 앞쪽(y<−0.06m), 높이0.215~0.39m에서 중심선을 가로지르는87개 삼각형을 제거해 앞트임을 실제로 열었다. 전체 정점 인덱스와 남은 면의 UV를 보존했다. 의도적으로 끊어야 하는 이 연결을 단순히 늘어짐 지표에서 제외한 것이 아니라 실제 시험 모델에서 제거했다.
- 마지막 검증은 바로 앞에서 계산한 동일한 천 좌표 캐시를 재사용한다. 따라서 연결 면 제거의 전후 차이는 새로운 무작위 물리 결과 때문이 아니다. `CLOTH_REUSE_CACHE=1`은 같은 계산 표면/조건의 캐시에만 사용한다.
- 같은 카메라/같은 몸 이동으로4초30fps 재계산. 전후 비교는 `outputs/tripo-pixel-cloth-comparison.mp4`와 `.png`.

원래 정적인 후드/스카프 모델은 보존하며 관성 시험 파일을 갱신한다. 실제 달리기/관절 굽힘/옷끼리 상호 충돌/최종 도트 품질은 별도 검증이다.

최종 재검증: 같은31/75/76/90/120/150프레임의 로브 모서리 최대 길이 비율은 각각1.159/1.179/1.431/1.038/1.076/1.103배. 여섯 프레임 모두2배 초과0개. 이전 최댓값151.503배와 비교하며,87개 잘못된 연결 면을 실제 제거했으므로 완전히 같은 모서리 집합은 아니다. 남은 면에서 과도한 국소 늘어짐이 없는지 확인한 검사다. 전150프레임의 모든 자기관통이나 모든 모서리를 검사했다는 뜻은 아니다.

베이크 재생 최대 좌표 오차1.49e-8m 유지, MP4120프레임 디코딩 통과. 관성 시험에서의 앞트임 연결 결함 수정은 완료했지만, 전체 게임용 의상 품질 판정은 실제 모션/충돌/도트 검증 전까지 보류한다.

## 후속: 의상 간 충돌과 후드 관성

사용자가 스카프가 로브 안으로 들어가고 후드가 고정된 점을 지적했다. 앞트임 연결 검사만으로 의상 상호 충돌을 검증한 것이 아니었다.

- 움직이는 로브 계산 표면에 Collision을 추가해 스카프가 몸의 작은 충돌체뿐 아니라 로브에도 부딪히게 했다.
- 계산 표면과 렌더 메시 사이의 오프셋으로 생기는 관통에는 실제 변형된 로브 외면을 대상으로 스카프 정점의6mm 접촉 간격을 보정한다. Cloth를 대체한 수작업 흔들림이 아니라 시뮬레이션 후의 위치 접촉 보정이다. 양방향 의상 힘 전달을 완전히 구현했다는 뜻은 아니다.
- 후드 뒷부분/끝은 몸의 가속도에 반응하는 감쇠 회전 스프링으로 계산한다. 초당360회 적분, 선형/비선형 복원력과 감쇠를 사용한다. 앞쪽 얼굴 입구는 고정 가중치0이며 후드 전체를 자유 Cloth로 바꾸지 않았다. 스프링 시작값은 `hood_spring`에 기록하며 실제 천 재질을 측정한 물성치는 아니다.
- 충돌 조건이 달라졌으므로 이전 캐시 재사용을 차단하고 전체150프레임을 새로 계산한다.
- `scripts/verify-garment-contact.py`는 베이크된 실제 로브 외면/스카프 꼬리의150프레임 교차를 검사한다. 목 부착부는 대상에서 제외한다. BVH 후보에 비공면 선분-삼각형 교차 검사를 추가하며, 다른 신체 부위/공면 접촉/프레임 사이 연속 충돌까지 보장하지 않는다.
- `scripts/render-hood-reaction.py`로 급정지 전/최대 반응/감쇠 후의 후드 측면 확대를 만든다. 카메라를 고정해 실제 후드 형상 변화를 비교한다.

- 이번 실행에서는 로브 Collision 추가로 교차가 해결되어 렌더 정점의 추가 접촉 투영 보정 횟수는0이었다. 위치 보정만으로 관통을 숨긴 결과가 아니다.
