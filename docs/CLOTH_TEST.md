# Tripo 새 모델 천 관성 시험

2026-10-23. 사용자가 물리/관성 시험 또는 필요한 선행 단계를 요청했다.

## 시험 범위

`outputs/tripo-pixel-shaped.blend`의 후드/스카프 수정 모델을 사용한다. Kimodo 달리기 적용본이 아니라 **T자 자세 이동 장치**로 출발, 정속 이동, 급정지, 반대 방향 이동을 시험한다. 카메라는 몸을 따라가므로 화면에서는 몸이 고정되어 보인다. 실제 시뮬레이션의 몸은 월드 Y축으로 이동한다.

- Blender 4.5.13 Cloth, 30fps, 150프레임 중 처음30프레임 안정화. 이후120프레임/4초를 영상에 포함.
- 스카프171정점, 로브333정점의 별도 저밀도 계산 표면. 스카프 뿌리와 로브 상부 고정. 실제 Tripo 렌더 메시를 완전히 잘라 분리한 것이 아니라, 독립 계산 표면의 변위를 원본에 전달하는 시험 구조다.
- 중력, 관성, 공기 저항, 몸 충돌과 자기 충돌 사용. 움직임을 사인파로 직접 만든 것이 아니다. 움직이는 것은 시험용 몸의 위치이며 천은 물리 계산 결과다.
- 머리/몸통/골반/두 다리/두 팔을 단순 타원체 충돌체로 근사. 정확한 원본 표면 충돌이나 관절이 굽혀지는 달리기 충돌은 검증하지 않았다.
- Cloth quality12, collision quality6, 자기 충돌 거리0.003m, 몸 충돌 거리0.004m. 로브 윗부분3줄 고정, 굽힘 강성12. 스카프 뿌리2줄 고정, 굽힘 강성0.8.
- 계산 표면의 가까운4정점 변위를 가중 평균해 원본에 전달. 위치가 겹치는 UV 정점의 변위는 일치시켜 균열을 방지한다. 이 방식이 최종 의상 리깅을 대체하지는 않는다.

## 확인된 문제와 조정

첫 시험에서 스카프가 중력에 내려앉고 급정지 후 지연 반응을 보였지만, 로브 앞트임 주변이 거칠게 접혔다. 밑단 부근의 변형 가중치가 다시0으로 줄어드는 경계를 제거하고 상부 고정 범위를 확대했으며 굽힘 강성과 자기 충돌을 추가해 재시험했다.

물리 반응의 발생과 게임용 외형 품질을 구분한다. 정지 시 스카프가 아래로 처져 폭이 줄어드는 현상은 중력 반응이지만, 팀원 그림의 긴 스카프 실루엣과는 별도 미술 조정이 필요하다. 앞트임 주변의 변형은 재생 영상에서 판단하며, 이번 시험만으로 의상 품질 통과나 관통0건을 주장하지 않는다.

## 결과/재현

- `scripts/test-pixel-cloth.py`: 실제 물리 계산, 프레임 렌더, 계산 표면 좌표 캐시, Blender 재생용 Shape Key 베이크.
- `scripts/encode-pixel-cloth.py`: 120프레임 30fps MP4/GIF, 네 시점이 아닌 네 시간대의 접촉시트. MP4 디코딩 프레임 수 검사.
- `outputs/tripo-pixel-cloth-test.blend`: 원본 외형과 물리 베이크를 포함한 별도 시험 파일. 계산용 Cloth는 베이크 후 비활성화해 저장된 재생 결과를 유지한다.
- `outputs/tripo-pixel-cloth-cache.npz`: 두 계산 표면의150프레임 좌표.
- `docs/logs/tripo-pixel-cloth.json`: 설정 및 매 프레임 끝단 위치/최대 변위.

후드/스카프 정적 수정본은 그대로 보존한다. 다음 단계는 옷자락의 변형 전달과 실루엣 품질 정리 후 실제 골격 모션에서 팔/다리 충돌 시험이다. 반복 루프, 최종6색 도트, 실시간 게임엔진 천은 아직 미검증이다.

## 최종 판정

- MP4 120프레임/30fps/4초 디코딩 검사 통과.
- 저장한 Blender를 다시 열어31/75/76/90/120/150프레임을 확인. 베이크 좌표와 재생 좌표의 최대 오차 약1.49e-8m로 재생 재현 통과.
- 몸이 정지한76~105프레임 사이 스카프 끝 평균점 누적 이동거리 약0.236m, 로브 밑단 평균점 약0.020m. 정지 후에도 천이 움직이는 반응을 수치로 확인. 누적 이동거리이며 한쪽으로 늘어난 길이가 아니다.
- **게임용 외형 품질은 미통과.** 스카프 처짐/몸 뒤 가림과 로브 앞트임의 거친 변형이 남는다. 몸 충돌체가 근사이며 두 천 사이 상호 충돌은 검증하지 않았다. 자기 충돌을 켰다는 사실만으로 관통이 없다고 보장하지 않는다.
- 다음 우선순위: 실제 옷자락에 맞는 열린 단일 천 표면 및 정확한 변형 전달 → 스카프가 처져도 읽히는 실루엣/부착각 검토 → 골격 적용 후 달리기 충돌. 물리 수치만 반복 조정해 완료로 처리하지 않는다.
